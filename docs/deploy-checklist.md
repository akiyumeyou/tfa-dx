## 1. 公開前にやること

### 1-1. 公開URLを `site.ts` に反映する

デプロイすると `https://tfa-dx-〇〇.vercel.app` のようなURLが発行されます。
独自ドメインを使う場合は、Vercelでドメインを設定してからそのURLを使います。

`src/data/site.ts` の `url` を実際のURLに書き換えてください。

```ts
url: "https://tfa-dx.vercel.app",  // ← 実際に公開するURLに変更
```

**なぜ必要か**：SNSでシェアしたときのサムネイル画像（OGP画像）のURLは、この値をもとに組み立てられます。
ここが実際のURLと違うと、**SNSに画像が表示されません**。

### 1-2. 掲載内容の最終確認

| 確認すること | 場所 |
| --- | --- |
| 講師・メンター9名のプロフィールと肩書 | `/instructors` ページ |
| 全6回の日付・タイトル・担当講師 | `/program` ページ |
| 第6回の会場（ときわプラザ アスティ2F 第5会議室） | `/program` ページ |
| 事前説明会の日時（2026年9月2日(水) 19:00〜） | トップページ |
| 問い合わせ先メール（tfadx2026@gmail.com）が受信できるか | フッター |
| 定員・参加要件・修了条件 | トップページ「開催概要」 |

**講師・メンターご本人への確認**：写真とプロフィール文の掲載について、事前に許諾を得ているかご確認ください。

### 1-3. 変更をGitHubに反映する

`site.ts` を書き換えたら、変更を保存してGitHubへプッシュします。Vercelが自動で再デプロイします。

```bash
git add -A
git commit -m "公開URLと申込フォームのリンクを設定"
git push
```

※このあたりはClaude Codeに「プッシュして」と頼めば代わりに実行します。

## 2. 公開直後にやること

### 2-1. 各ページの表示確認

- [ ] トップページ `/`
- [ ] プログラム詳細 `/program`
- [ ] 講師・メンター `/instructors`
- [ ] **スマートフォンの実機**で3ページとも表示崩れがないか
- [ ] 申込ボタン・説明会ボタンを押して、正しいフォームが別タブで開くか
- [ ] QRコード2つをスマホで実際に読み取って、正しいフォームが開くか
- [ ] トップの講師カードが横に流れ、タップでプロフィールが開くか
- [ ] ブラウザのタブに紫色のロゴ（ファビコン）が出ているか

### 2-2. SNSシェアの見え方を確認する

公開URLをSNSに貼ったとき、画像とタイトルが正しく出るか確認します。
以下のツールにURLを入れると、実際の見え方をプレビューできます。

| サービス | ツール |
| --- | --- |
| X（Twitter） | https://cards-dev.twitter.com/validator |
| Facebook | https://developers.facebook.com/tools/debug/ |
| LINE | https://poker.line.naver.jp/ |

正しく表示されるもの:
- 画像：AIアイコンと女性のバナー画像（1200×630）
- タイトル：とくしまフューチャーアカデミーDX | AIを味方につけ、徳島で輝くDX人材へ

### 2-3. 【重要】あとから画像やタイトルを変えた場合

X・Facebook・LINEは、一度読み込んだ画像やタイトルを**自社サーバーに保存（キャッシュ）して使い回します**。
そのため、公開後にOGP画像やタイトルを差し替えても、**SNSでは古いものが表示され続けます**（数日〜数週間）。

そのときは上記のツールにURLを入れて「再取得（Scrape Again / Preview card）」を実行してください。
最新の内容を読み直してくれます。

**初回公開時は何もしなくて大丈夫です。**キャッシュがまだ存在しないためです。

## 4. 公開後に内容を修正したくなったら

修正箇所ごとのファイルの場所です。Claude Codeに「〇〇を直して」と伝える際の目安にしてください。

| 直したいもの | ファイル |
| --- | --- |
| 申込フォームのURL・公開URL・問い合わせ先・開催概要 | `src/data/site.ts` |
| 全6回の日程・タイトル・課題・特徴・FAQ | `src/data/program.ts` |
| 講師・メンターのプロフィール | `src/data/people.ts` |
| 写真の差し替え | `assets/people/` に同じファイル名で置き、`npm run images` を実行 |
| ヒーロー画像・アイキャッチ・OGP・ファビコン | `assets/site/` を差し替え、`npm run images` を実行 |

画像まわりの詳しい手順は `public/images/README.md` に書いてあります。

修正後は、変更をGitHubにプッシュすればVercelが自動で再デプロイします（1〜2分で反映）。
