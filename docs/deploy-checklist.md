## 1. 公開前にやること

### 1-1. 公開URLを `site.ts` に反映する

デプロイすると `https://tfa-dx-〇〇.vercel.app` のようなURLが発行されます。
独自ドメインを使う場合は、Vercelでドメインを設定してからそのURLを使います。

`src/data/site.ts` の `url` を実際のURLに書き換えてください。

```ts
url: "https://tfa-dx.vercel.app",  // ← 実際に公開するURLに変更
```

**なぜ必要か**：SNSでシェアしたときのサムネイル画像（OGP画像）のURLは、この値をもとに組み立てられます。
ここが実際のURLと違うと、**SNSに画像が表示されません**。

### 1-2. 掲載内容の最終確認

| 確認すること | 場所 |
| --- | --- |
| 講師・メンター9名のプロフィールと肩書 | `/instructors` ページ |
| 全6回の日付・タイトル・担当講師 | `/program` ページ |
| 第6回の会場（パーク テレコメディア アスティとくしま2階 第5会議室） | `/program` ページ |
| 事前説明会の日時（2026年9月2日(水) 19:00〜） | トップページ |
| 問い合わせ先メール（tfadx2026@gmail.com）が受信できるか | フッター |
| 定員・参加要件・修了条件 | トップページ「開催概要」 |
| 申込締切（2026年9月9日(水) 23:59）と抽選の注記 | トップページ「開催概要」 |

**講師・メンターご本人への確認**：写真とプロフィール文の掲載について、事前に許諾を得ているかご確認ください。

### 1-3. 変更をGitHubに反映する

`site.ts` を書き換えたら、変更を保存してGitHubへプッシュします。Vercelが自動で再デプロイします。

```bash
git add -A
git commit -m "公開URLと申込フォームのリンクを設定"
git push
```

※このあたりはClaude Codeに「プッシュして」と頼めば代わりに実行します。

## 2. 公開直後にやること

### 2-1. 各ページの表示確認

- [ ] トップページ `/`
- [ ] プログラム詳細 `/program`
- [ ] 講師・メンター `/instructors`
- [ ] **スマートフォンの実機**で3ページとも表示崩れがないか
- [ ] 申込ボタン・説明会ボタンを押して、正しいフォームが別タブで開くか
- [ ] QRコード2つをスマホで実際に読み取って、正しいフォームが開くか
- [ ] トップの講師カードが横に流れ、タップでプロフィールが開くか
- [ ] ブラウザのタブに紫色のロゴ（ファビコン）が出ているか

### 2-2. SNSシェアの見え方を確認する

公開URLをSNSに貼ったとき、画像とタイトルが正しく出るか確認します。
以下のツールにURLを入れると、実際の見え方をプレビューできます。

| サービス | ツール |
| --- | --- |
| X（Twitter） | https://cards-dev.twitter.com/validator |
| Facebook | https://developers.facebook.com/tools/debug/ |
| LINE | https://poker.line.naver.jp/ |

正しく表示されるもの:
- 画像：AIアイコンと女性のバナー画像（1200×630）
- タイトル：とくしまフューチャーアカデミーDX | AIを味方につけ、徳島で輝くDX人材へ

### 2-3. 【重要】あとから画像やタイトルを変えた場合

X・Facebook・LINEは、一度読み込んだ画像やタイトルを**自社サーバーに保存（キャッシュ）して使い回します**。
そのため、公開後にOGP画像やタイトルを差し替えても、**SNSでは古いものが表示され続けます**（数日〜数週間）。

そのときは上記のツールにURLを入れて「再取得（Scrape Again / Preview card）」を実行してください。
最新の内容を読み直してくれます。

**初回公開時は何もしなくて大丈夫です。**キャッシュがまだ存在しないためです。

## 2-4. Google検索に載せる（あと1ステップ）

サイト側の準備は **2026-08-12に完了しています**。以下はもう動いています。

| 用意したもの | 確認用URL |
| --- | --- |
| サイトマップ（Googleに全ページを伝える） | https://tfa-dx.vercel.app/sitemap.xml |
| robots.txt（クロールを許可する） | https://tfa-dx.vercel.app/robots.txt |
| 構造化データ（講座・FAQの内容をGoogleに伝える） | 各ページのHTMLに埋め込み済み |
| canonical URL（重複ページ扱いを防ぐ） | 3ページとも設定済み |

残っているのは **Google Search Console への登録** だけです。これはGoogleアカウントでの
ログインが必要なので、以下を手で行ってください。

### 手順

1. https://search.google.com/search-console にGoogleアカウントでログイン
2. 「プロパティを追加」→ **URLプレフィックス** を選び、`https://tfa-dx.vercel.app` を入力
3. 所有権の確認画面で **「HTMLタグ」** を選ぶと、こんなコードが表示されます

   ```html
   <meta name="google-site-verification" content="abcdefg123456..." />
   ```

   この `content="..."` の中身（`abcdefg123456...` の部分）をコピーします。

4. Vercelの管理画面 → プロジェクト `tfa-dx` → Settings → Environment Variables で登録

   | 項目 | 入力する値 |
   | --- | --- |
   | Key | `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` |
   | Value | 手順3でコピーした文字列 |
   | Environment | Production にチェック |

5. 保存したら Deployments タブ →最新のデプロイの「…」→ **Redeploy**（環境変数は再デプロイしないと反映されません）
6. Search Consoleの画面に戻って「確認」を押す

   ※ Claude Codeに「確認コードは〇〇です」と伝えてもらえれば、手順4〜5を代わりに実行します。

7. 確認が通ったら、左メニューの **「サイトマップ」** に `sitemap.xml` と入力して送信

### 【重要】「TFADX 2026」で上位を取るには、サイト側だけでは足りません

調べたところ、**同じ事業名のサイトが他にも稼働しています**（過去年度・関連団体のもの）。

| サイト | 状態 |
| --- | --- |
| https://tfa.life/ | 稼働中。「TFA 2026 開催概要ページを更新中」と表示 |
| https://mirea.hp.peraichi.com/tfadx | 稼働中。URLに `tfadx` を含む |
| https://awa-onna.com/tfa/ | 稼働中（NPO法人GWEI） |
| 徳島県公式（令和3年度の募集ページ） | 稼働中。**県のドメインなので検索に非常に強い** |

当サイトは2026年7月にできたばかりの新しいURLで、他サイトからのリンクがほぼありません。
検索順位は「そのページが他からどれだけリンクされているか」で大きく決まるため、
**文章やタグの調整だけでは、実績のある既存サイトを追い抜けない可能性があります。**

効果が大きい順に、以下は**主催者・受託者側での調整が必要**です（コードでは解決できません）。

1. **徳島県の公式サイトから当サイトへリンクしてもらう** ← 最優先。
   主催が徳島県なので依頼しやすく、効果も一番大きいです
2. **tfa.life（TFA本体サイト）の2026年度ページから、DXコースとしてリンクしてもらう**
3. **独自ドメインを取る**（例：`tfadx2026.jp`）。
   `vercel.app` のままだと評価が乗りにくいです。
   ただし**やるなら今のうち**です。検索に載ったあとにURLを変えると最初からやり直しになります

また、**「TFADX」は米国の投資信託のティッカーシンボルでもあります**。
英語圏の金融サイトが同じ文字列のページを持っているため、
「TFADX」単体より **「TFADX 2026」「とくしまフューチャーアカデミー 2026」** のほうが
狙いやすい検索語です。チラシやSNSで案内するときは、この呼び方で統一すると効果が上がります。

### 検索に出るまでの目安

登録してから **数日〜2週間** ほどかかります。すぐには出ません。
急ぎたい場合は Search Console の上部の検索窓にURLを貼って
「インデックス登録をリクエスト」を押すと早まることがあります。

「とくしまフューチャーアカデミー」のような固有名詞は比較的早く、
「徳島 DX 女性 無料」のような一般的な言葉で上位に出るには時間がかかります。

## 4. 公開後に内容を修正したくなったら

修正箇所ごとのファイルの場所です。Claude Codeに「〇〇を直して」と伝える際の目安にしてください。

| 直したいもの | ファイル |
| --- | --- |
| 申込フォームのURL・公開URL・問い合わせ先・開催概要 | `src/data/site.ts` |
| 全6回の日程・タイトル・課題・特徴・FAQ | `src/data/program.ts` |
| 講師・メンターのプロフィール | `src/data/people.ts` |
| 写真の差し替え | `assets/people/` に同じファイル名で置き、`npm run images` を実行 |
| ヒーロー画像・アイキャッチ・OGP・ファビコン | `assets/site/` を差し替え、`npm run images` を実行 |

画像まわりの詳しい手順は `public/images/README.md` に書いてあります。

修正後は、変更をGitHubにプッシュすればVercelが自動で再デプロイします（1〜2分で反映）。
