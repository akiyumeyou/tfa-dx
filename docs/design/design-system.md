# TFA-DX デザインシステム

最終更新: 2026-07-26
定義場所: `src/app/globals.css` の `@theme`（Tailwind CSS v4）

| トークン | 値 | 用途 |
| --- | --- | --- |
| `primary` | `#7B68AE` | 見出しの装飾、バッジ、特徴①の背景、ステッパーの円 |
| `primary-dark` | `#5B4B87` | フッター背景、白背景上の強調テキスト |
| `primary-light` | `#C4B5E3` | ヒーローのグラデーション上端、罫線 |
| `primary-pale` | `#ECE7F7` | カードの枠線、タグ背景 |

| `accent-hover` | `#DC9760` | CTAボタンのホバー |

| `ink` | `#2D2D3F` | 本文・見出し |

| `canvas` | `#F8F6FB` | ページ背景 |

### コントラスト比の検証結果

| 組み合わせ | 比 | WCAG AA |
| --- | --- | --- |
| `accent` 背景 + `ink` 文字（CTAボタン） | 6.6:1 | 合格 |
| `accent` 背景 + 白文字 | 1.9:1 | **不合格・使用禁止** |
| `accent-strong` 文字 + 白背景 | 5.4:1 | 合格 |
| `ink-muted` 文字 + `canvas` 背景 | 7.5:1 | 合格 |

CTAボタンに白文字を使わない理由は `docs/decisions/2026-07-26.md` の項目3を参照。

## タイポグラフィ

- フォント：Noto Sans JP（`next/font/google`、weight 400 / 500 / 700）
- 本文：16px / 行間 1.9（`globals.css` の `body`）
- 見出し h1：`text-3xl`（モバイル） → `text-5xl`（デスクトップ）
- 見出し h2：`text-2xl` → `text-3xl`
- 補足テキスト：`text-sm`（14px）。本文には使わない

## レイアウト

- 最大幅：1200px 中央配置
- 左右パディング：モバイル 16px / デスクトップ 32px
- セクション間：`py-16`（モバイル） → `py-24`（デスクトップ）
- グリッド：モバイル1カラム → タブレット2カラム → デスクトップ最大4カラム
- 角丸：8px（`--radius-card`）で統一

## アクセシビリティ

- インタラクティブ要素は最低 44×44px（`min-h-[44px]`）
- フォーカスリング：`:focus-visible` に3pxのprimary色アウトライン
- 「本文へスキップ」リンクを `layout.tsx` の先頭に配置
- `prefers-reduced-motion` でアニメーションを無効化
- ボタンラベルは必ずテキストを含む（アイコンのみにしない）
- 装飾要素には `aria-hidden="true"`
- `scroll-padding-top: 5rem` でstickyヘッダーがアンカー先を隠さないようにしている
