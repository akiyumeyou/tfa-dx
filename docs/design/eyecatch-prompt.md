# アイキャッチ画像の生成プロンプト

トップページ上部の横長バナー（およびSNSシェア画像）用。
ChatGPT等の画像生成にそのまま貼り付けて使えるようにしたものです。

---

## 押さえるべき条件（なぜその指定なのか）

| 条件 | 理由 |
| --- | --- |
| **生成サイズは 1536×1024（横長）** | ChatGPTで作れる最も横長の比率。ここから帯とOGPを切り出す |
| **人物は右寄せ（右1/3）** | 左側に見出しテキストを重ねられる余白を作るため |
| **顔は画面の上下中央付近に** | 帯（3:1）に切り出す際、**上下が大きく切り落とされる**ため |
| **人物は右端から10%以上内側に** | スマホでは左右も少し切られるため、端に寄せすぎると顔が切れる |
| **文字・ロゴを入れない** | サイト側で見出しを載せる。AIが生成する日本語は字形が崩れやすい |
| **背景は明るく余白多め** | 上に文字を重ねても読めるようにするため |

### 切り出し後のイメージ

```
生成画像 1536×1024
┌─────────────────────────────┐
│           （切られる）             │
├─────────────────────────────┤ ← ここから
│  余白（左）        │   人物（右1/3）   │   帯として使う範囲
├─────────────────────────────┤ ← ここまで
│           （切られる）             │
└─────────────────────────────┘
```

## プロンプト（そのままコピーして使えます）

```
横長のWebサイト用バナー画像を作ってください。サイズは1536×1024。

【シーン】
明るく清潔な自宅のリビングまたはコワーキングスペースで、40代前後の日本人女性が
ノートパソコンに向かい、前向きな表情でやわらかく微笑んでいる。自然光が差し込む。

【構図】※重要
・人物は画像の右側3分の1に配置し、右端からは10%以上内側に置く
・左側3分の2は背景の余白として空けておく（あとで見出し文字を重ねるため）
・人物の顔は画像の上下方向で中央付近（上から40〜55%の位置）に置く
・上下は大きく切り落として横長の帯として使うため、重要な要素を上端・下端に置かない

【色・雰囲気】
・全体に淡い紫（#7b68ae）と白を基調とした、やわらかく上品なトーン
・アクセントに淡いオレンジ（#e8a87c）を少しだけ
・背景はぼかし気味で明るく、圧迫感のない余白を多く

【AIらしさの表現】
・画面まわりに、AIを象徴する細く繊細なグラフィック（つながったノード、
　やわらかい光の粒、AIアイコンなど）を控えめに重ねる
・派手なSF風・ロボット風にはしない

【禁止】
・文字、ロゴ、透かしを一切入れない
・過度な装飾、暗いトーン、コラージュ風
・顔が不自然に崩れないよう、人物は自然な写真風に
```

## 生成したあとの手順

1. 画像を `assets/site/hero-band.png` に上書き保存する（トップページ用）
   ※プログラム詳細ページ用は `assets/site/eyecatch.png`
2. `npm run images` を実行する

これだけで、以下が自動で作り直されます。

| 生成物 | サイズ | 用途 |
| --- | --- | --- |
| `public/images/hero-band.webp` | 1600×533 | トップページ上部の横長バナー |
| `public/images/og/ogp.jpg` | 1200×630 | SNSシェア時のサムネイル |

### 頭や顎が切れてしまうとき

`scripts/build-images.mjs` の `SITE_IMAGES` にある `focusY` を調整します。

- `0` = 画像の上端から切り出す（人物が上寄りの写真向け）
- `0.5` = 中央から切り出す（既定）

2026-07-27に採用した写真は顔が上から30%の位置にあったため `focusY: 0.15` にしています。
