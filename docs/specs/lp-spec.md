# TFA-DX LP 仕様

最終更新: 2026-07-26

## プロジェクト概要

徳島県が主催する女性向けDX人材育成プログラム「とくしまフューチャーアカデミーDX（TFA-DX）」のLP。

- デプロイ先: Vercel
- レスポンシブ: モバイルファースト
- リポジトリ: https://github.com/akiyumeyou/tfa-dx

## ターゲットとコンバージョン設計

**ターゲットの心理**
「興味はあるけど、自分にできるか不安」という女性が、安心して一歩を踏み出せる設計にする。

**施策**
1. 不安を先に解消してからCTAを配置する（Q&A → CTA の順）
2. 社会的証明：徳島県主催であること、講師の実績を目立たせる
3. 「無料」「初心者OK」「オンライン」の3点を繰り返し見せる
4. CTAは複数配置：ヘッダー / ヒーロー / Q&A後 / 開催概要下 / フッター
5. 事前説明会（9/2）への導線を用意（「まずは説明会だけでも」）
6. 修了証発行を明記（行政の権威性）
